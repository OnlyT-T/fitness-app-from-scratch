1. BẢNG THUẬT NGỮ CHUNG
| Muốn làm        | Tailwind        | CSS tương đương    |
| -------------   | -------------   | ------------------ |
| Background      | `bg-blue-500`   | `background-color` |
| Text color      | `text-white`    | `color`            |
| Font size       | `text-xl`       | `font-size`        |
| Bold            | `font-bold`     | `font-weight`      |
| Padding         | `p-4`           | `padding`          |
| Margin          | `m-4`           | `margin`           |
| Margin top      | `mt-4`          | `margin-top`       |
| Padding X       | `px-4`          | left + right       |
| Padding Y       | `py-4`          | top + bottom       |
| Width           | `w-full`        | `width: 100%`      |
| Height          | `h-screen`      | `height: 100vh`    |
| Border radius   | `rounded-lg`    | `border-radius`    |
| Shadow          | `shadow-md`     | `box-shadow`       |
| Flexbox         | `flex`          | `display: flex`    |
| Grid            | `grid`          | `display: grid`    |
